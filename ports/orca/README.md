# dawn & dusk for Orca

A theme plugin for the **Orca** app (not used by the CSS package, the docs or the skill). It paints Orca in the design
system: **dawn** in light mode and **dusk** in dark, both named "dawn & dusk", each with a matching terminal palette and
the docs' code colours.

## Install

From a checkout of this repository:

```sh
orca plugin install ./ports/orca
```

Run it again after pulling changes to update the installed copy. It is a content-only plugin, so it installs without
an approval prompt.

## Turn it on

Orca holds one theme for light mode and one for dark, so pick "dawn & dusk" in both:

1. Settings → Appearance: set Theme mode to **System** (follows macOS), Light or Dark.
2. **Light theme** → dawn & dusk, then click **Use its terminal colors**.
3. **Dark theme** → dawn & dusk, then click **Use its terminal colors**.
4. Light and dark **editor theme** → **Same as app theme**, so code uses the system's syntax colours.

## How it's made

Everything here except this README is generated by [`scripts/build-orca-theme.mjs`](../../scripts/build-orca-theme.mjs)
from `ds/tokens.css`. Change the tokens or the script, never the JSON, then rebuild:

```sh
npm run build:orca    # this plugin only; npm run build includes it
```

| File | What it is |
| --- | --- |
| `orca-plugin.json` | The plugin manifest (its version follows `package.json`) |
| `themes/dawn.json`, `themes/dusk.json` | App themes: Orca's colour tokens and the editor's code colours |
| `terminal/dawn.json`, `terminal/dusk.json` | Terminal palettes |

The script resolves every `var()` and `color-mix(in oklab, …)` to a plain colour, because Orca themes take colours only.
Where Orca needs a colour the system has no token for, it uses the system's own recipes: sidebars use the side-nav rail
tone, tabs use the `dd-tabs` underline, selection is inverted like `::selection`, and dawn's status and terminal colours use
the `.dd-code` mixes that hold 4.5:1 on the light page.
