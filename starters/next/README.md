# Next.js starter

Requires Node.js 22.12+ (or 24+).

    npm install
    npm run dev

Edit app/page.jsx. Run npm run build and npm start for production.
CSS and ThemeScript are installed once in app/layout.jsx. ThemeScript runs before hydration to restore the saved theme.
The package comes from the versioned GitHub release; no npm account is needed.
Do not import dawn-and-dusk/auto into React-owned markup.
